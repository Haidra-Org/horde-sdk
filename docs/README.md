# Horde SDK documentation

Horde SDK provides typed Python clients, request and response models, generation parameters, and worker-building
primitives for the Haidra ecosystem. Choose a path based on what you need to accomplish:

- [Tutorial](tutorial/README.md): learn the SDK by completing a small, working request.
- [How-to guides](how-to/README.md): follow procedures for a specific client, request, backend, or worker task.
- [Reference](reference/README.md): look up contracts, state transitions, errors, endpoints, and Python APIs.
- [Explanation](explanation/README.md): understand why the SDK is layered and how its major abstractions fit together.

The [Topics](topics.md) page follows one subject across those four kinds of documentation. Shared
[Horde concepts](haidra-assets/docs/README.md) define ecosystem language, while the
[Haidra standards](haidra-assets/docs/meta/documentation.md) govern contributions to this documentation.

## Start here

Install the current stable package with Python 3.12 or newer:

```console
python -m pip install horde-sdk
```

Then [create your first image request](tutorial/first-image.md), or use the
[client selection matrix](reference/client-behavior.md) if you already know the level of control you need.
